# 주택담보대출 원리금 계산기 (Mortgage Calculator)

주택담보대출의 상환 방식별 월 상환액과 상환 스케줄을 계산하는 프로젝트입니다.

🔗 **바로 사용하기:** https://bynylee.github.io/mortgage-calculator/

## 기능
- **중도상환 계산**: 현재 잔액·금리·만기일 기준으로 중도상환 후 월 납입액(만기 유지) 또는 단축 기간(납입액 유지), 이자 절감액, 중도상환수수료 계산
- **신규 대출 계산**: 상환 방식별 월 상환액과 스케줄

## 상환 방식
- 원리금균등상환
- 원금균등상환
- 만기일시상환

## 입력값
- 대출 원금
- 연 이자율
- 대출 기간 (개월)
- 거치 기간 (선택)
